# TechPilot AI

A fast, responsive English-language website about AI tools, technology tutorials, and practical software guides, built with Astro.

## Stack

- [Astro](https://astro.build/)
- GitHub for source control
- Cloudflare Pages for hosting

## Run locally

1. Install a current Node.js LTS release.
2. Clone this repository.
3. Run `npm install`.
4. Run `npm run dev` to start the development server.
5. Run `npm run build` to create the production build in `dist/`.

## Deployment

For Cloudflare Pages, connect this GitHub repository and use:

- Build command: `npm run build`
- Build output directory: `dist`

## Before public launch

- Add the real domain and configure a sitemap.
- Add a real contact email and the site operator's details.
- Review the privacy policy and terms against the actual services enabled and applicable law.
- Publish substantial, original, fact-checked articles and verify all product details.
- Test mobile layouts, accessibility, links, metadata, and the production build.
- Do not add analytics or advertising scripts until the relevant privacy disclosures and settings are ready.

The presence of policy pages alone does not guarantee approval for advertising programs such as Google AdSense.
